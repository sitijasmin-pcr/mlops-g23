# MLOps Starter Project

## Deskripsi
Repository praktikum MLOps Pertemuan 2 untuk mempelajari fondasi pemrograman, Git, GitHub, dan setup lingkungan kerja.

## Struktur Project
- frontend: antarmuka aplikasi
- backend: API dan business logic
- model: kode dan artefak machine learning
- data: raw dan processed data
- tests: pengujian
- docs: dokumentasi

## Setup
1. Clone repository
2. Buat virtual environment
3. Install requirements

## Tech Stack
Python, Git, GitHub

## Development Workflow
Pengembangan menggunakan feature branch, meaningful commit, dan merge ke main.
